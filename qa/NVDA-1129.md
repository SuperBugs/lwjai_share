# 英伟达新增1500亿美元回购，股价应该涨多少个点？

新闻已核实：英伟达今天（9月28日）确实宣布新增1500亿美元回购授权，剩余总额2350亿，股价盘前涨约1.2%。正在核对最后一个数据点。

## 结论

**理论上，回购本身不应该让股价涨；现实中回购带来的溢价大约在1%左右。今天盘前已经涨了1.1%～1.3%，基本已经反映进股价了。** "1500亿除以市值，所以该涨2.8%"这种算法是不成立的。

## 先算清楚规模

| 项目     | 数值                                                 |
| ------ | -------------------------------------------------- |
| 新增授权   | 1500亿美元，约占市值的 **2.8%**（市值约5.42万亿美元，上周五收盘价225.07美元） |
| 剩余授权总额 | 2350亿美元，约占市值的 **4.3%**                             |
| 执行期限   | 到2028财年结束（约2028年1月底），大约16个月                        |
| 每季度回购  | 约440亿美元，是最近每季度约200亿的**两倍多**                        |
| 每天的买盘  | 约7亿美元，只占日均成交额（约240～340亿美元）的 **2%～3%**              |

## 为什么不能按2.8%算

1. **回购花的是股东本来就有的钱。** 回购用的是公司的现金和未来的自由现金流，这些已经算在市值里了。举个例子：一家公司值100元，其中10元是现金，共10股，每股10元。拿10元现金回购1股之后，公司剩90元、9股，每股还是10元。"股本减少、每股收益增加，所以股价该涨"是个常见误区：每股收益确实高了，但公司也少了这笔钱。
2. **授权不等于执行**，而且这笔钱要分16个月慢慢花。
3. **大部分早就在预期里。** 英伟达本来每季度就回购约200亿，管理层也说过要把50%以上的自由现金流还给股东。今年5月瑞银就猜过这次可能给到1500亿。

## 那为什么还能涨一点

* **返还股东的比例大幅提高。** 美银统计，2022到2025年英伟达只把47%的自由现金流还给了股东，同类大公司大约是80%。新计划下，回购加分红每年大约2000亿美元，而过去12个月的自由现金流只有约1270亿。就算现金流继续增长，也要拿出大部分来回购和分红，远高于之前"约50%"的说法。
* **释放信号。** 管理层敢花这么多钱，说明他们对Rubin这一代产品带来的现金流有信心，也不觉得现在的股价贵。
* **缓解了两个担忧。** 一是第二季度自由现金流从486亿美元掉到约213亿（大客户账期拉长，加上为Rubin备货）；二是"循环融资"，也就是英伟达把现金投给OpenAI、Anthropic这些客户，客户再拿钱买它的芯片。

## 可以参考的例子

* **学术研究**：美股宣布回购时，平均超额收益早年大约3%，近些年在1%～2%。公司市值越大、回购占市值比例越小，反应越弱。
* **英伟达自己**：之前宣布的500亿、600亿、800亿回购都是跟财报一起公布的，股价主要看业绩。2024年8月那次，第二天股价还跌了6%多；今年5月那次，股价也基本没动。
* **这次是单独公告**：盘前上涨1.2%左右，对应市值增加约650亿美元，远小于1500亿。说明市场并没有把回购金额当成等额的新增价值。

## 长期来看

如果按现价全部执行完，大约能注销10.4亿股，约占总股本的4.3%，每股收益会因此增加约4%。但这本质上相当于每年约3%的现金回报，跟分红差不多，是一点点体现出来的，不会在公告当天一次涨完。另外要注意：第二季度回报股东的260亿美元已经超过了当季自由现金流，同一季度公司还发了250亿美元的债。如果现金流恢复不了，回购可能会放慢，因为授权并不等于承诺。

**总结一下**：回购本身大约值1个点，盘前已经涨出来了。接下来的涨跌主要看11月下旬的第三季度财报、Rubin的出货情况，以及现金流能不能回升。
