# CoreWeave发布30亿可转债，估算合理跌幅

**我的初步判断：假设大盘、AI算力板块和经营预期不变，以融资消息公布前的价格为基准，下调4%—7%、中枢约5%，属于我认为可以解释的短期反应。**\
如果单独只有这笔可转债，我会给更温和的负面判断；把股票发行安排及持续融资压力一起考虑，才提高到上述区间。**这不是“稀释多少就该跌多少”的计算结果，也不是跌到这个幅度就一定见底。**

另外的3,500万股股票发行安排，不能理解为今天已经全部卖出。公司表示，预计与可转债承销方约定，至少在可转债购买协议签订30天后，才通过该安排售股；实际销售还取决于市场、股价和资金需求。部分远期售股方式也不是卖出时资金就立即进入公司。([美国证券交易委员会](https://www.sec.gov/Archives/edgar/data/1769628/000176962826000429/crwv-20260917.htm))

所以，这次需要同时考虑两件事：**可转债的融资条件，以及未来股票供给增加的预期。**

## 二、为什么不是“潜在稀释约一成，就该跌一成”？

做个简化测算：**假设定价参考股价85美元、转股溢价25%**，则初始转股价约为：

85×1.25=106.25美元85\times1.25=106.25美元

30亿—35亿美元本金，对应的基础转股数量约为**2,824万—3,294万股**。以公司二季度约**5.51亿股加权平均股数**作为粗略股本参考，相当于约**5.1%—6.0%**；这个股本口径只是估算，并非今天精确的完全摊薄股数。([CoreWeave](https://investors.coreweave.com/news/news-details/2026/CoreWeave-Reports-Strong-Second-Quarter-2026-Results/default.aspx))

另外，3,500万股发行额度约相当于上述参考股本的**6.4%**。

但不能把这两项相加，直接得出股价该跌约11%—12%。原因是：

* 借债时，公司同时拿到现金。不是凭空增加30亿—35亿美元损失；未来转股时，相应债务也会被清偿。
* 发行股票也会换回资金。如果按公允价值发行，忽略费用，股数增加本身并不等于每股价值同比例下降。
* 可转债还有保护安排和结算选择。本次公司可以选择现金、股票或混合结算，拟议的capped call也会影响最终经济稀释。([美国证券交易委员会](https://www.sec.gov/Archives/edgar/data/1769628/000176962826000429/ex9911.htm))

因此，**真正要打折的是融资成本、资金使用回报、未来持续融资的风险，以及短期股票供给压力，而不是把潜在新增股数当成损失。**

### 那我为什么仍然给4%—7%的负面区间？

**主要担心的是“融资依赖”，不只是这一笔债的利息。**

按拟议规模和票息计算，这笔债新增的年现金利息大约是**0.71亿—1.01亿美元**，单看这项并不足以让我给出很大的股价折价。但公司上半年的经营现金流为**36.63亿美元**，设备及资本化软件的现金支出为**141.17亿美元**，两者相减约为－104.54亿美元；二季度净利息费用已经达到**6.4亿美元**。这说明扩张投资对外部资金的需求很大——这里的104.54亿美元是上述现金流差额，**不是经营亏损**。

我的推演是：“又发可转债，同时准备股票发行”会让投资者重新衡量未来每股收益中，有多少可能被融资成本及新增股本分走。这比一次性的票息增加更值得警惕。

不过，也不能把融资自动解读为需求崩了。同批材料披露，**7月各产品规格价格上涨约25%，二季度签订合同的预期贡献利润率，比近期季度高5—10个百分点**。这些是公司披露的经营指标和预期，不等于已经兑现的净利润，但至少提供了另一面：融资也可能是在支持回报改善中的业务扩张。

**综合起来，我认为需要折价，但目前不足以仅凭这次公告，就认定应当出现两位数的永久价值损失。**

## 三、具体跌到哪里，我会怎么判断？

**关键是从“公告前价格”算，不是从昨收机械地算，更不是从已经跳水后的现价再扣一次。**

我尚未取得可靠的公告前分钟成交价，下面用**公告前85美元**举例，而不是把85美元当作已核实的实时价格：

| 相对公告前跌幅 | 85美元对应价格    | 我的理解                               |
| ------- | ----------- | ---------------------------------- |
| **4%**  | **81.60美元** | 进入我的基本反应区间                         |
| **5%**  | **80.75美元** | 我的中枢判断                             |
| **7%**  | **79.05美元** | 已反映较明显的融资及供给担忧                     |
| **10%** | **76.50美元** | 需要检查是否还有更差条款、板块下跌或基本面重估，不能只归因于股数稀释 |

换成公式，就是：

我的基本事件区间≈公告前价格×93%—96%\boxed\{\text\{我的基本事件区间}\approx\text\{公告前价格}\times93\\%\text\{—}96\\%}

**特别注意你说的“盘前跳水”：从上涨变成少涨，也可能已经充分反映这次冲击。例如，假设公告前较昨收上涨6%，随后从那个价格下跌4%—7%，对应的昨收涨跌幅其实约为＋1.8%至－1.4%**。并不意味着还要等它相对昨收跌到－7%，才算“跌够了”。

### 我的最终判断

**单看这次组合融资，我倾向于把公告前价格下方4%—7%视为可以解释的短期折价区间。跌到8%—10%以上，可以开始审视是否出现情绪或供给冲击放大，但绝不能仅凭跌幅就认定便宜——股价原先是否高估，是另一道题。**

下一项关键事实是最终定价。公司计划在**美东9月17日收盘后，即北京时间9月18日凌晨起**完成定价；最终转股溢价、票息，以及capped call的保护上限，都可能改变上述判断。
