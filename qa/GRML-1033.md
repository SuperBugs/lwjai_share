但这里有个非常重要的区别：

它宣布的是“申请扩大勘探范围”，不是许可证已经批准，更不是探明储量、可开采产量或者利润翻倍。公司公告标题强调控制范围翻倍，正文却写的是已经提交申请；看标题和看正文，得到的确定性完全不同。([环球新闻发布](https://www.globenewswire.com/news-release/2026/09/21/3365568/0/en/greenland-mines-more-than-doubles-control-position-in-the-sarfartoq-rare-earth-magnet-district-in-west-greenland.html "Greenland Mines More Than Doubles Control Position in the"))

## 4. 这轮利好有多硬，后面还能不能持续？

政策方向有真实变化，但具体公司的经济收益，目前还不能按股价涨幅同比例确认。这是我区分“利好存在”和“上涨是否已经透支”的关键。

接下来最值得看的是三类证据，而不是更多“我们欢迎历史性协议”的表态：

| 后续证据                       | 对估值意味着什么              |
| -------------------------- | --------------------- |
| **明确的政府投资、贷款担保或有约束力的采购协议** | 从“可能受支持”变成可核实的资金或商业安排 |
| **许可证获批、融资落实、开工及投产节点推进**   | 项目离产生现金流更近            |
| **只有意向、申请和远期乐观估值**         | 仍主要依赖市场情绪，不能直接支持盈利兑现  |

最大的风险，是市场提前把“美国可能支持开发”交易成了“这些公司一定能赚钱”。反过来，也不能仅因单日涨幅巨大，就认定马上适合做空：估值是否透支和题材何时退潮，是两个不同的问题。

**一句话概括：安全协议点燃格陵兰资源题材，GRML扩区申请再添一把火；真正决定后劲的，是美国的钱、订单和开发许可会不会落到这些公司身上。**
