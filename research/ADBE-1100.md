#### 最重要的分歧：收入仍增长，但新增订阅明显放缓

年化经常性收入，简称**ARR**，可理解为当前订阅合同按一年折算的收入规模，不等于当季已经确认的营业收入。

按公司披露的同汇率、已四舍五入的期末ARR余额计算：

| 观察项          | 数值与含义                                                    |
| ------------ | -------------------------------------------------------- |
| 2026年第三季度净增加 | 275.0亿－271.0亿＝**约4.0亿美元**                                |
| 上年同期净增加      | 247.4亿－240.8亿＝**约6.6亿美元**                                |
| 同比变化         | 粗算减少约四成；这是余额差额估算，不是公司单独披露的精确净新增同比。                       |
| 全年目标要求       | 公司维持全年ARR增长10.2%的目标，以256.6亿美元年初基数推算，第四季度需净增加约**7.8亿美元**。 |

上述计算采用官方数据表与全年指引。第四季度通常有更强的企业业务贡献，公司也表达了相应预期，因此不能仅因需要接近第三季度两倍的净增加，就判定指引无法兑现。**但达到约7.8亿美元只是兑现现有目标，不自动构成超预期。**([Adobe](https://www.adobe.com/cc-shared/assets/investor-relations/pdfs/01906202/b75st5a4rwea.pdf "https://www.adobe.com/cc-shared/assets/investor-relations/pdfs/01906202/b75st5a4rwea.pdf"))

管理层的解释是：主动把部分流量引导至免费产品，先提高使用频率，再选择合适时机转化为付费，同时没有优先推进部分涨价措施。这是合理的商业解释，**但还不是免费战略已经成功的证明**；当前公开信息不足以完整量化免费用户的付费转化率和回收周期。([Adobe](https://www.adobe.com/cc-shared/assets/investor-relations/pdfs/adbe-q3fy26-transcript.pdf "https://www.adobe.com/cc-shared/assets/investor-relations/pdfs/adbe-q3fy26-transcript.pdf"))

#### AI既是增长机会，也是对原有收费模式的考验

公司披露，AI原生产品ARR超过6.5亿美元，同比增长超过150%；Firefly应用与点数包ARR环比增长40%。前者相当于总ARR约2.4%以上，但该指标并不涵盖所有受AI功能影响的传统订阅收入。([Adobe](https://www.adobe.com/cc-shared/assets/investor-relations/pdfs/01906202/c6yetrerew.pdf "https://www.adobe.com/cc-shared/assets/investor-relations/pdfs/01906202/c6yetrerew.pdf"))

因此，不能得出“Adobe没有AI收入”，也不能得出“AI已经足以抵消全部竞争压力”。真正需要验证的是：**新增AI收费能否覆盖免费获客、模型运行成本，以及传统订阅潜在的降价或替代压力。**

此外，Semrush已于4月28日完成收购并纳入报表，不能把当前全部收入增长都当作原有业务的自然增长。([Adobe](https://www.adobe.com/cc-shared/assets/investor-relations/pdfs/adbe-10q-q326-final.pdf "https://www.adobe.com/cc-shared/assets/investor-relations/pdfs/adbe-10q-q326-final.pdf"))
