### 2.2 最容易误判的地方：NAV增长不全是“投中了”

基金披露的H1每股净值变化为：

| 每股NAV桥接     | 金额          |
| ----------- | ----------- |
| 2025年末NAV   | 19.93美元     |
| 投资运营贡献      | ＋7.27美元     |
| ATM发行影响     | **＋7.10美元** |
| 2026年6月末NAV | **34.30美元** |

约 **49.4%的每股NAV增量来自ATM发行影响**，而不是底层投资升值。高于净值发行新股，既可能降低老股东持股比例，又可能增厚老股东的每股净资产；这两件事并不矛盾。

更值得警惕的是净值与股价的分离：

| 期间      | 基金披露NAV回报    | 基金披露市价回报    |
| ------- | ------------ | ----------- |
| 2025全年  | **＋209.59%** | **－47.96%** |
| 2026上半年 | **＋72.12%**  | **－15.90%** |

这说明：买入时支付的折溢价，可能比底层资产涨了多少更影响最终收益。管理人扩张资产规模、提高每股NAV，并不自动保证二级市场股东赚钱。

### 2.5 价值锚与敏感性

以季后新增投资按成本入账、股数不变为前提，对**非现金类投资整体估值**做压力测试：

| 假设            | 推算每股净资产      | 含义                      |
| ------------- | ------------ | ----------------------- |
| 其他投资不调价       | **约34.30美元** | 接近已披露净值；不是新增169百万美元“利润” |
| 非现金类投资整体下调10% | **约32.48美元** | 当前价格与调整后净值的差距明显收窄       |
| 非现金类投资整体下调20% | **约30.66美元** | 当前股价不再相对该压力净值有折价        |

计算采用现金类投资约7.707亿美元、其他投资约8.693亿美元、其他净负债约521万美元及4,765.73万股；未计入未来费用、新融资、税项或后续资产重估。**这是净值敏感性，不是三套股价目标。**([Destiny](https://destiny.xyz/api/fund-documents/12/file))

由此得到两个有用的尺度：

第一，单纯从31.31美元回到34.30美元，仅有约9.5%的股价空间。要支持更大的上涨，需要新净值上升，或者市场重新愿意支付溢价。

第二，在上述静态模型中，当前价格相当于给非现金类投资打约16.4%的折扣。这个缓冲并非没有价值，但还不足以不问底层估值、费用和退出条件就认定“捡到便宜”。反过来，若新融资确实提高持仓价值，压力测试也可能低估真实NAV；目前缺少足够的成交条款来确认这一点。
